Settings

Controller settings

Spin-down: a hard drive is put to sleep once nothing has read from or written to it for this long (0 = never; SSDs are never touched). Very short times wear the drives, because each spin-up counts against their start/stop rating; 20–30 min is a good value. The dashboard's own SMART reads don't count as activity and never wake a sleeping drive.

Fan control

–

Drag points to change the curve. Double-click empty space to add a point, right-click a point to remove it. The dashed line is the current temperature.

Kp: fan % added per °C above target. Ki: slowly adds more fan while the temperature stays above target. Drives heat up slowly, so keep Ki small and Kd at 0 unless you know you need it.
